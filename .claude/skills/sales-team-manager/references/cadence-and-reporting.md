# Cadence and reporting

## Daily huddle (10–15 min, before the first dial block)

```
1. Yesterday (3 min): team numbers vs. target. Shout out one specific good call (play 20 seconds if possible).
2. Today's focus (2 min): the weekly hot topic, e.g. "booking ask with two options, then silence."
3. Drill (5–8 min): rapid-fire on the focus, interrupt-and-redo, everyone speaks at least once.
4. Logistics (2 min): niche and time blocks for today, callbacks due at exact times, list ready.
```

Energy matters, but no hype that leads to pressure tactics. End on the first dial.

## Daily schedule ([EXAMPLE] for a setter team calling local businesses)

Plan dial blocks around the niche timing rules (recipient's local time, 8am–9pm only):

| Time | Block |
|---|---|
| Huddle + role-play | 15–30 min |
| Early block | Trades/cleaners at opening; auto repair at opening |
| Late morning | Gyms/martial arts (10am–2pm) |
| Early afternoon | Daycare nap time; salon/barber 2–4pm Tue–Thu; restaurants 2–4pm |
| After 5 | Trades/cleaners |
| Gaps | Tape review, list building, GHL cleanup |

Callbacks always happen at the exact promised time.

## EOD report (GHL)

Each rep submits this every day before logging off. Build it as a GHL form or a custom-values note, or a pinned team-channel post with a fixed format. Every call is also logged on the contact with the rep as Setter Assigned.

```
EOD: [Name]   [Date]
Dials:                     __
Connects:                  __
Owner conversations:       __
Demos booked:              __   (names + times)
Callbacks set (exact time):__
"Send me info" follow-ups: __
DNC requests honored:      __
Best call (contact link + why):
Worst call (contact link + the second it turned):
One thing I'll do differently tomorrow:
```

Closers:

```
EOD: [Name]   [Date]
Demos scheduled / showed / qualified:  __ / __ / __
Closes:                                __
Cash collected today:                  $__
Care plans sold:                       __
No-shows rebooked:                     __
Lost deals + main reason (works / trust / money):
Call to review in game tape:
```

Manager: read every EOD the same night. Reply to at least one line per rep. Flag inconsistencies between EOD numbers and GHL data. Report integrity is a performance standard.

## Weekly

| Meeting | Length | Content |
|---|---|---|
| Game tape | 60 min | Hot topic; 3–5 calls; model, role-play, takeaway |
| KPI review | 20 min | Team funnel vs. targets, find the bottleneck, set next week's hot topic |
| 1:1s | 20–30 min each | See `performance-management.md` |

## Monthly

- Commission reconciliation against **cash collected** in GHL/payments; apply clawbacks per the written plan.
- Ladder review: who's ready to move up, who needs a calendar adjustment, who's on a PIP.
- Recruiting pipeline check: how many candidates are warm right now?
- Script review: do the scripts still match what's working on tape? Update the training modules if so.
- Compliance audit: random sample of calls for honesty and DNC/calling-hour rules.
