# The Value Equation for agency offers

```
Value = (Dream Outcome × Perceived Likelihood) ÷ (Time Delay × Effort & Sacrifice)
```

Increase the top two and shrink the bottom two. A change to any one of them changes perceived value, and it often costs nothing to deliver.

## The four drivers, translated for agencies

| Driver | What it means to a local business owner | Agency levers |
|---|---|---|
| **Dream Outcome** (raise) | More booked jobs, a phone that rings, looking legit next to competitors, not losing leads at night | Name the outcome in their words: "customers who find you on Google can book you". Tie it to revenue, not features |
| **Perceived Likelihood** (raise) | "Will this actually work for *me*?" | A pre-built demo of *their* site, case studies in the same niche, reviews, a named guarantee, a named person who builds it, a clear process |
| **Time Delay** (shrink) | How long until it's live and paying off | A fixed launch date ("live 14 days after kick-off"), quick wins in week 1, showing the demo now |
| **Effort & Sacrifice** (shrink) | Calls, writing copy, sending photos, learning software, risk of looking dumb | Done-for-you copy and photos, one kick-off call, no logins to manage, the agency handles hosting and edits |

**Rule of thumb:** people buy convenience. Local owners are busy, so the denominator is usually the cheapest and most powerful lever.

## Scorecard (AUDIT mode)

Score each driver 1–10 **from the prospect's point of view**, not the agency's.

| Driver | Score | Evidence (what in the offer earns the score) | Biggest gap | Fix (suggestion for owner) |
|---|---|---|---|---|
| Dream Outcome (10 = vivid, specific, desired) | | | | |
| Perceived Likelihood (10 = they already believe it) | | | | |
| Time Delay (10 = slowest, 1 = instant) | | | | |
| Effort & Sacrifice (10 = heavy lift, 1 = zero effort) | | | | |

Quick index: `(DO × PL) ÷ (TD × ES)`. Use it only to compare versions of the same offer. It is not an absolute grade.

Always tell the user which **one** driver to fix first, and why.

## 7-point irresistibility check

The structure is paraphrased from common $100M Offers summaries. Mark each item yes or no.

1. Is the perceived value far above the price, ideally around 10:1 (5:1 at minimum)?
2. Is it sold into a starving crowd (pain, money, easy to reach, growing)?
3. Is there risk reversal, meaning a named guarantee that the agency actually honours?
4. Are there at least three named bonuses, each tied to an objection, with defensible values?
5. Is there a *real* reason to act now (real scarcity or urgency)?
6. Is it a bundle competitors can't easily line up against (not "a 5-page website")?
7. Does the name say who it's for and what they get?

How to read the result: 6–7 yes means strong. 4–5 means the value is there but risk reversal, bonuses or urgency are missing. 3 or fewer means it is a commodity, and the prospect will compare you on price.

## Commodity test

If the offer can be described as "[deliverable] for [price]" (for example, "5-page website for $2k"), the prospect will compare it with Wix, Fiverr and their nephew. Reframe it around outcome, speed and effort. Then the comparison becomes "do it yourself" against "done for you in 14 days, guaranteed".
