# OBJECTION-PROOF mode: map objections to offer components

Hormozi's idea, paraphrased: the best place to handle an objection is inside the offer, before it's ever said. Every recurring objection is a missing bonus, guarantee, proof asset or delivery change.

## Process
1. Collect the real objections from call notes and reviews (setter notes logged in the CRM, closer call recordings). Use the defaults below if there are none.
2. Tag each one with the value driver it attacks: **Dream Outcome**, **Likelihood**, **Time**, **Effort**, or **Price/Trust/Authority**.
3. Map each one to an offer component.
4. Write one honest closer line for each.
5. Flag any component that isn't real yet. It becomes a to-do for the owner, not something to say on a call.

## Default agency objection map

| Objection | Driver | Offer component that removes it | Honest closer line |
|---|---|---|---|
| "Too expensive." | Price / Dream outcome | Cost-of-inaction anchor, a lower tier, payment option *if the owner approves one* | "What were you expecting? … Let's look at what one extra job a week is worth to you." |
| "I can get Wix for $20 a month." | Effort | Done-for-you everything, edits included in the care plan | "You can. The difference is who does the work. Would you rather build it or have it done?" |
| "My nephew does websites." | Likelihood / Time | A fixed launch date, a named builder, the demo already exists | "That's great. Is he building it now, or is it a 'one day' thing?" |
| "I've been burned before." | Likelihood | Demo before payment, conditional launch-date guarantee, references in their niche | "That's exactly why we build it first. You've seen it before you pay anything." |
| "I don't have time." | Effort | One kick-off call, done-for-you copy and photos sourced from Google | "It's one 20-minute call. We do the rest." |
| "Does a website even bring customers?" | Dream outcome / Likelihood | Click-to-call, booking, a Google Business Profile tune-up bonus, a niche case study (only if real) | "Here's what it's designed to do: …" No promises of numbers. |
| "I need to talk to my spouse/partner." | Authority | Book the decision-maker onto the demo call (the setter's job), plus a shareable demo link | "Totally fair. Can we get them on the 15-minute look together?" |
| "Let me think about it." | Usually hidden price, trust or effort | Find the real one: "What part are you unsure about?" Then use the matching row | Ask, don't push. |
| "What if I don't like it?" | Likelihood | Revisions until launch (if honoured), named guarantee | State the guarantee exactly as written. |
| "Is there a catch? Is it a scam?" | Trust | Free demo with no card or contract, real address and reviews, a named team | "Really free. The honest catch is we hope you like it enough to make it your real site." |

## Output format
For each objection: **Objection → Driver → Component (exists? yes/no) → Closer line → Setter line (only if an approved setter line exists).**
