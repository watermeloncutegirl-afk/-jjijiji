# Claude Skills for Sales, Agencies and Hormozi-Style Sales Teams

Research date: 2026-10-23. Every repo was checked on GitHub. Star counts are approximate.

**Main finding:** No popular repo is built specifically for high-ticket cold-call closing or for selling an agency. The best setup combines a few strong general packs with small, targeted repos.

### Hormozi's principles for managing sales reps (summary)
- **Hiring:** Recruit all the time. Screen for coachability, speed, listening and hunger. Expect heavy turnover.
- **Onboarding (14 days):** Reps memorise the script, then drill tone and objections, then shadow. They get half a calendar after passing tests and a full one only after hitting KPI.
- **Daily role-play:** Interrupt and correct constantly ("Stop. Go back. Try it like this."). Rotate the focus: intro, discovery, pitch, objections.
- **Weekly call review:** Review 3 to 5 recorded calls, then drill the weakest phase.
- **Pay:** About 50/50 base and variable. Commission is paid on cash collected.
- **Career ladder:** SDR, then closer, then senior closer, then manager. Everyone starts at the bottom.
- **Standards:** Track show rate as well as close rate. Remove average performers who won't improve.

## Recommended install stack

```bash
# 1. Official Anthropic sales plugin (discovery, objections, close plans)
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install sales@knowledge-work-plugins

# 2. Negotiation / cold calling / offers psychology
npx skills add wondelai/skills/negotiation --global
npx skills add wondelai/skills/predictable-revenue --global
npx skills add wondelai/skills/hundred-million-offers --global

# 3. Hormozi closing + rep management (copy the SKILL.md folders)
git clone https://github.com/Wrenbjor/Hormozi-Marketing-Agent-Skills
git clone https://github.com/prayceo/claude-skills-public
cp -r Hormozi-Marketing-Agent-Skills/<skill-folder> ~/.claude/skills/
cp -r claude-skills-public/<hormozi-brain-folder> ~/.claude/skills/

# 4. Cold call skill
git clone https://github.com/TheCraigHewitt/sales-skills
cp -r sales-skills/skills/cold-call ~/.claude/skills/

# 5. Agency-specific
#   Web design: coreyhaines31/marketingskills + zubair-trabzada/ai-marketing-claude + anthropics/skills (frontend-design)
#   AI automation: czlonkowski/n8n-mcp + czlonkowski/n8n-skills
```

Read every third-party SKILL.md before installing it. Most of these repos have few stars and are unreviewed.

## Gaps worth filling with a custom skill
1. A full live high-ticket cold-call skill covering gatekeepers, call branching and moving from pain to close.
2. ROI-based discovery and pitch skills for AI automation agencies.
3. A Hormozi-style sales manager skill combining CLOSER call scorecards, a role-play drill generator and a KPI dashboard.
