# Cornwall website cold-calling kit

This kit is for selling websites to Penryn and Falmouth businesses that don't have one.

| Folder / file | What's in it |
|---|---|
| `leads/penryn.md` / `.csv` | 38 Penryn (TR10) businesses with no website |
| `leads/falmouth.md` / `.csv` | 56 Falmouth (TR11) businesses with no website |
| `scripts/05-top-20-call-sheet.md` | **Start here.** The top 20 prospects, with tailored openers |
| `scripts/00-master-cold-call-script.md` | The full call: openers, discovery, pitch, close, voicemail, follow-ups |
| `scripts/01-niche-scripts.md` | Scripts for 8 niches: trades, cafés, hair, B&Bs, retail, marine, services, garages |
| `scripts/02-offer-and-pricing-talk-tracks.md` | Free mockup, packages, guarantees, honest urgency |
| `scripts/03-practice-roleplay-prompts.md` | Prompts for Claude to roleplay six sceptical owners and score your calls |
| `scripts/04-objection-handling.md` | 76 objections with responses, plus a cheat sheet |
| `prompts/local-claude-lead-search.md` | A prompt for Claude on your PC to find more leads using your browser |
| `sales-tools/` | 9 open-source Claude sales/cold-calling skill repos; see `sales-tools/README.md` |

Before calling, Google each business quickly and check its number against the TPS/CTPS do-not-call lists. Replace `[PRICE]`-style placeholders with your real figures.
