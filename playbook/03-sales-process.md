# The Sales Process, Start to Finish

```
Lead list → Prospect audit → Demo built → Setter call → Demo call (Closer) → Proposal + deposit → Kick-off → Live in 14 days → Care plan / review / referral
```

| Stage | Owner | Output | Logged in GHL as |
|---|---|---|---|
| 1. Lead list | Researcher / setter | Niche + city list, tiered A/B/C/Skip | New Lead |
| 2. Prospect audit | Researcher | Verified facts: what's costing them customers, what we'd fix, what caught our eye | Audited |
| 3. Demo build | Designer | Live demo URL (noindex, demo footer) | Demo Ready |
| 4. Setter call | Setter | Booked 15–30 min demo, owner on the call, handoff note | Booked |
| 5. Demo call | Closer | Exact price, decision | Showed / No-show / Won / Lost |
| 6. Proposal + deposit | Closer | Signed agreement, deposit paid, kick-off booked | Won – Onboarding |
| 7. Kick-off → launch | Delivery | Site live 14 days after kick-off | Live |
| 8. After launch | Account owner | Day-7 check-in, Day-30 review ask, referral ask, care plan | Active Client |

## Roles
- **Setter:** gets past the gatekeeper, opens honestly, answers the price with the approved ballpark only, books the demo. Never quotes custom prices or terms.
- **Closer:** runs the demo call, gives the exact price, handles objections honestly, collects the deposit, books kick-off.
- **Delivery:** builds the real site from the demo and hits the 14-day launch.
- **Manager:** hiring, daily role-play, weekly call review, KPIs, compliance.

## Setter → closer handoff note (GHL)
- Owner name and title they go by; who else decides
- How new customers find them today
- Taking new customers? (Y/N)
- Price reaction to "around two thousand"
- The true detail used in the opener
- Demo link and booked time (their time zone)

## Core KPIs to track weekly
Dials → connects → owner conversations → demos booked → demos showed → closed → cash collected → care plans added. Set targets from your own first 2–4 weeks of data (see `team/kpis-and-diagnostics.md`).
